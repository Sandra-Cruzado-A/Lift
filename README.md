# Lift: inglés para hablar con soltura

App web para aprender inglés desde el móvil: conversaciones guiadas, simulacro de entrevista de trabajo, taller de escritura, reto diario, juegos e inglés técnico de aviónica.

Se puede instalar en la pantalla de inicio y funciona sin conexión (el reconocimiento de voz sí necesita internet). El progreso se guarda en el navegador de cada persona.

## Actualizar la app

1. Sube el nuevo `index.html` sustituyendo el anterior.
2. En `sw.js`, cambia la línea `VERSION` (por ejemplo, de `lift-2.0.0` a `lift-2.0.1`) y súbelo también.
3. Los móviles recibirán la versión nueva la próxima vez que abran la app con conexión (a veces hace falta cerrarla y abrirla dos veces).
